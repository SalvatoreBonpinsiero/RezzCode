<h3>⚡ Features</h3>
<ul>
  <li><b>Built for RezzOS:</b> Native integration and standalone execution on <a href="https://github.com/Rezzev/RezzOS">RezzOS</a>.</li>
  <li><b>Citrus Palette:</b> Deep warm graphite background with lime, grapefruit, and lemon syntax highlights.</li>
  <li><b>Zero External Dependencies:</b> Runs entirely via standard Python <code>tkinter</code>.</li>
  <li><b>Built-in Runner:</b> Integrated output console panel (<code>F4</code> / <code>F5</code>) for fast script execution.</li>
  <li><b>Interactive Elements:</b> Clickable web links, fast Find & Replace, and smart auto-indentation.</li>
</ul>

<h3 id="quick-start">🚀 Quick Start</h3>

<pre><code>git clone https://github.com/SalvatoreBonpinsiero/rezzcode.git
cd rezzcode
python rezzcode.py</code></pre>
